## Goals:

1. **Learn Astro**: Develop an understanding of the Astro Framework to create a functional portfolio site.

2. **Practice Tailwind**: Practice TailwindCSS to create a visually appealing site

3. **Share my Learnings**: Create my first post to show off the websites capabilities!

## Reflection:

While this may have been a setup project, I certainly learned a good deal about content-driven web development with Astro, styling with Tailwind, and much more. I also realized my everlasting hate for CSS.

### Setting up Astro Site:

For the main setup of the Site, I followed (all be it, loosely) the "build a blog" tutorial from the official docs.  This got me most of the way for the main features of this site, but also gave me much room for improvement.  For example, styling, some navigation, and blog history all were customized further from this basic site.

One thing that I didn't fully figure out during the short development was adding HTML/JS content into the .MD files used for individual posts/projects.  While having each individual post as a markdown file is infinitely easier for now, going into the future it may cause problems with other projects which need some content embedded in the post.  This will be a problem that I will address when it comes up, however.

### To Hell with CSS (And thank you Tailwind)

I love web development with all of my heart, but the horrendous experience that is trying to remember what the hell everything does and what specific cases everything is useful for in CSS completely brought my hype down.  I initially tried to use plain CSS for this project, but after getting stuck in a endless loop of Google "How to do...." then for it not to work, I ended up using Tailwind for styling.  Easily one of the best choices of my life.  Tailwind CSS combined with autocomplete is seriously a force to be reckoned with.

Styling I found to be relatively quick and fun with Tailwind.  Being able to quickly and accurately style any component of the page allowed me to come up with more interesting and creative ways to style the page.  I'm a big sucker for diagonal lines, so a lot of the geometry present withing the page is either trapezoidal, diagonal, or square.  I tried to incorporate as many interactive bits, like with the buttons and project cards, which animate and morph as the user interacts with them.
